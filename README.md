# Anbani Cards

An interactive flashcard app for learning the 33 letters of the Georgian alphabet. It includes four study units, letter-to-sound and sound-to-letter modes, spaced repetition, progress tracking, keyboard shortcuts, and optional Georgian speech synthesis when a compatible system voice is available.

## Use

Open the [live app](https://apeir99n.github.io/anbani-cards/) in a browser. No installation or account is required; progress is stored locally in the browser.
